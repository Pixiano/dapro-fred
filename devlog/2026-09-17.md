    `pythonw` specifically to avoid a console flash). Verified end-to-end:

    both came up correctly.
- **Found and fixed the real cause of recurring flickering terminal
  windows** — earlier in this project's history, `DaProDrive_SuhaniMergeCheck`
  and `DaProDrive_SuhaniQuotaCheck` scheduled tasks had been "fixed" by
  setting the task's `Settings.Hidden = $true`, which turned out to only
  control Task Scheduler UI visibility, not the actual console window.
  Real fix: rewrite the task's Action `Arguments` to include
  `-WindowStyle Hidden` directly on the PowerShell invocation. Also caught
  the same root cause in Claude Code's own ponytail-plugin statusline hook
  (`~/.claude/settings.json` → `statusLine.command`), which was launching
  PowerShell with no window suppression at all on every refresh — added
  `-WindowStyle Hidden` there too.
